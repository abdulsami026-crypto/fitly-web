Questions

Which format should I choose?

JPG suits photos and works everywhere. PNG keeps sharp edges and transparency. WebP gives smaller files for the web.

What happens to transparent areas?

PNG and WebP keep transparency. JPG cannot, so transparent areas turn white.

Does converting to PNG reduce the file size?

Usually not. PNG is lossless, so photos often get larger as PNG. Use JPG or WebP for smaller files.

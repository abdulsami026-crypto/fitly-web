Questions

Do these QR codes expire?

No. The code simply contains your text or link, so it works as long as that link works.

What does error correction do?

Higher levels let a code still scan when it is dirty or partly covered, but they make the code denser.

Can I use a Wi-Fi code?

Yes. Phones that scan it offer to join the network. Keep the printed code somewhere private if the password is sensitive.

Questions

Is Fitly really free?

Yes. Every tool is free, with no watermark and no limit on how much you use it. Fitly runs on your own device, so it costs almost nothing to keep online.

Where do my files go?

Nowhere. Each tool runs inside your browser using your device's own power. There is no Fitly server waiting to receive files, which is also why the tools keep working offline.

Does it work on my phone?

Yes. Fitly is built for phones first, because most people meet a size limit while filling in a form on their phone. It works the same on a computer.

Why did my photo get smaller in pixels too?

Only when quality changes alone cannot reach the limit. The resizer lowers quality first; if the file is still too big, it reduces the width and height a little, always keeping the same proportions and never cropping.
